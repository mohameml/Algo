# Chapter : Introduction aux Algorithmes

## 1. Definition

> Un **algorithme** est une séquence finie d'instructions qui, lorsqu'elle est suivie, résout un problème ou effectue une tâche spécifique.

## 2. Caractéristiques

| Propriété | Description |
|-----------|-------------|
| **Entrée/Sortie** | Prend des données en entrée, produit un résultat en sortie |
| **Finitude** | Se termine après un nombre fini d'étapes |
| **Déterminisme** | Chaque étape est définie sans ambiguïté |
| **Efficacité** | Utilise un minimum de ressources (temps, espace) |
| **Généralité** | Fonctionne pour une variété de données d'entrée |

- Composantes d'un algorithme :
    - **Instructions** — les étapes à suivre
    - **Variables** — les valeurs qui changent pendant l'exécution
    - **Contrôle de flux** — boucles, conditions, récursion
    - **Entrées / Sorties** — données fournies et résultats produits

## 3. Paradigmes Algorithmiques

| Paradigme | Idée | Exemple |
|-----------|------|---------|
| **Brute Force** | Tester toutes les possibilités | Recherche linéaire |
| **Divide & Conquer** | Diviser, résoudre, combiner | Merge Sort |
| **Greedy** | Choix localement optimal à chaque étape | Dijkstra |
| **Dynamic Programming** | Sous-problèmes chevauchants + mémorisation | Knapsack |
| **Backtracking** | Explorer et revenir en arrière | N-Queens |
| **Branch & Bound** | Explorer avec élagage (bornes) | TSP |
